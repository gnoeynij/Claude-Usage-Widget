# 계기판(instrument) 테마 + 그래파이트/실버 공통 팔레트 — 결정 기록

> 2026-07-23 세션에서 목업 4라운드로 수렴한 결정의 백업. **리뷰용 계획서가 아니라
> 이미 합의된 설계의 박제** — 멀티 세션 작업 + 컨텍스트 압축 대비. 구현 중 세부는
> 바뀔 수 있으나 *방향·무손실 요건*은 사용자 재합의 없이 바꾸지 말 것.

## 배경

- 사용자 디자인 방향: "카시오 빈티지 레트로 시계" 구조 × "Apple 집행" — 존(zone)
  분할·7-세그·분절 블록·마이크로캡스의 계기판 문법을, 시스템 팔레트·타뷸러
  숫자·헤어라인의 Apple 정제로 구현.
- 색: 현행 다크의 **군청(블루 캐스트) 제거**. iPhone 13 Pro Max **그래파이트 =
  다크 모드 / 실버 = 라이트 모드** (웜 뉴트럴).
- 기존 Liquid Glass 디자인은 **기본값으로 유지** — 계기판은 opt-in **테마**.

## 아키텍처 (2층 분리)

1. **공통 팔레트 (테마 무관, 전 서피스)** — 그래파이트/실버 토큰 일가가 기존
   glass 디자인·설정·가이드·마일스톤까지 일괄 적용. 블루 캐스트 금지.
2. **테마 (`store.theme: "glass" | "instrument"`, 기본 glass, 영속)** —
   - 토큰층: `.theme-instrument` 루트 클래스가 직각 radius·DSEG7 폰트 토큰 오버라이드
   - 뷰층: Normal/Mini/Detail 만 테마별 컴포넌트 분기. **투영·riskTone·scoped
     배선은 공유 뷰모델로 추출** (로직 이중 유지보수 금지)
   - 보조 서피스(설정 패널·가이드 프레임·마일스톤·토스트)는 1차에서 glass 고정
   - 신규 부품: `BlockGauge`(10칸 분절), `SegDigits`(DSEG7 + 꺼진 세그 "88" 고스트),
     존 프리미티브. instrument 전용.

## instrument 디자인 언어

- **7-세그는 세션 % 전용 서명** (Normal/Mini 히어로). DSEG7 Classic (SIL OFL)
  woff2 번들 — SUIT 폰트와 같은 자산 패턴. 뒤에 꺼진 세그 "88" 고스트 필수.
  Detail 은 타뷸러 숫자만 (밀도 영역에서 세그체 가독 저하).
- **게이지 = 10칸 분절 블록** — 그라데이션·고스트 밴드·도트 전면 폐기. 채움 색 =
  스톱라이트 임계색 단색. 투영 임박 경고는 텍스트(스트립/캡션)로.
- 라벨 = 마이크로캡스 (자간 0.12~0.14em, 10~11px 대문자).
- 존 = [마이크로캡스 헤더행 / 콘텐츠 / 헤어라인 구분]의 인셋 사각. radius 3~6px.
- 모델 4색(Opus=클레이, Fable=#bf5af2, Sonnet=#0a84ff, Haiku=#30d158)은 기능색으로
  유지 (Detail 스택 차트·범례).
