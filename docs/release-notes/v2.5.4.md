# v2.5.4 — Opus 5.5 cost accuracy

Anthropic has released Claude Opus 5.5. It is cheaper than Opus 5 in every pricing category, and the widget kept charging Opus 5's rates for it — so every Opus 5.5 session showed a higher total than it should have, with nothing looking wrong on screen.

## Fixed

- **Claude Opus 5.5 was priced at Opus 5's rates, too high in every category.** Opus 5.5 costs $4/$20 per MTok for input/output (Opus 5: $5/$25) and $5/$8 for 5-minute/1-hour cache writes (Opus 5: $6.25/$10), and its cache reads bill at 0.05× the base input price — $0.20 per MTok instead of Opus 5's $0.50. The widget had no entry for `claude-opus-5-5`, and because that id prefix-matches the existing `claude-opus-5` entry the lookup *succeeded* and quietly applied Opus 5's rates — the same failure mode v2.5.3 fixed for Fable 5.1, with no $0 gap and no warning. Input, output and cache writes ran 1.25× high and cache reads 2.5× high, so the displayed Opus 5.5 cost landed anywhere between 1.25× and 2.5× the correct figure depending on how much of a session was cache reads — and cache reads grow to dominate as a Claude Code session gets longer. Opus 5.5 is now priced explicitly, and the same unit test pins Opus 5's rates so the two can't be conflated again.

- **Claude Opus 5.5 in fast mode was priced at Opus 5's fast tier.** Fast mode on Opus 5.5 is $8/$40 per MTok (Opus 5 and Opus 4.8: $10/$50). The fast-mode lookup takes the first matching entry rather than the longest one, so `claude-opus-5-5` was being caught by the `claude-opus-5` fast entry. The more specific id is now checked first, and the unit test locks that ordering in.

## Notes

- Opus 5.5 is the second model family whose cache reads don't use the standard 0.1× multiplier, after Fable 5.1 and Mythos 5.1 at 0.025×. Every other price in the widget was re-checked against Anthropic's official pricing on September 28 and is unchanged.
- Anthropic's fast-mode table doesn't list Opus 5.5 cache rates separately. The widget applies the documented cache multipliers on top of the fast base price (cache reads: 0.05 × $8 = $0.40 per MTok), the same way it already does for Opus 5.
- The macOS `.dmg` code-signing fix from v2.5.2 still hasn't been confirmed on a real machine. If this one mounts for you that closes the question — if it doesn't, `hdiutil imageinfo` output on the downloaded file would help.
- All costs are *estimates* derived from local JSONL × official pricing (subscribers are not billed per-token).

## 수정

- **Claude Opus 5.5가 Opus 5 단가로 계산돼 모든 항목이 비싸게 나오던 문제.** Opus 5.5는 입력·출력이 MTok당 $4/$20(Opus 5: $5/$25), 5분·1시간 캐시 쓰기가 $5/$8(Opus 5: $6.25/$10)이고, 캐시 읽기는 기본 입력가의 0.05x인 $0.20으로 과금됩니다(Opus 5: $0.50). 위젯에는 `claude-opus-5-5` 항목이 없었고, 이 ID가 기존 `claude-opus-5` 항목에 prefix 매칭되기 때문에 조회가 *성공하면서* 조용히 Opus 5 단가를 적용했습니다 — v2.5.3에서 Fable 5.1에 대해 고친 것과 같은 경로로, $0으로 빠지지도 않고 경고도 없었습니다. 입력·출력·캐시 쓰기는 1.25배, 캐시 읽기는 2.5배 높게 계산돼, 세션에서 캐시 읽기가 차지하는 비중에 따라 Opus 5.5 비용이 실제의 1.25~2.5배 사이로 표시됐습니다 — Claude Code 세션이 길어질수록 캐시 읽기 비중이 커집니다. 이제 Opus 5.5 단가를 명시적으로 넣었고, 같은 단위 테스트에서 Opus 5 단가도 함께 고정해 두 모델이 다시 섞이지 않도록 했습니다.

- **Claude Opus 5.5의 fast 모드가 Opus 5의 fast 요율로 계산되던 문제.** Opus 5.5의 fast 모드는 MTok당 $8/$40입니다(Opus 5·Opus 4.8: $10/$50). fast 모드 조회는 가장 긴 항목이 아니라 처음 맞는 항목을 쓰기 때문에 `claude-opus-5-5`가 `claude-opus-5` fast 항목에 걸리고 있었습니다. 이제 더 구체적인 ID를 먼저 확인하며, 단위 테스트가 그 순서까지 고정합니다.

## 비고

- Opus 5.5는 캐시 읽기에 표준 0.1x 배수를 쓰지 않는 두 번째 모델군입니다(첫 번째는 0.025x인 Fable 5.1·Mythos 5.1). 위젯의 나머지 단가는 9월 28일 Anthropic 공식 단가표와 다시 대조했고 변경 사항이 없습니다.
- Anthropic의 fast 모드 표에는 Opus 5.5 캐시 단가가 따로 나와 있지 않습니다. 위젯은 문서에 명시된 캐시 배수를 fast 기본가 위에 적용합니다(캐시 읽기: 0.05 × $8 = MTok당 $0.40). Opus 5에 이미 쓰던 방식과 같습니다.
- v2.5.2의 macOS `.dmg` 코드 서명 수정은 아직 실기기에서 확인되지 않았습니다. 이번 dmg가 정상적으로 마운트되면 그것으로 확정되고, 여전히 안 되면 다운로드한 파일의 `hdiutil imageinfo` 출력을 알려주시면 도움이 됩니다.
- 모든 비용은 로컬 JSONL × 공식 단가표 기반 *추정치*입니다(구독 사용자는 실제 토큰당 과금 없음).
