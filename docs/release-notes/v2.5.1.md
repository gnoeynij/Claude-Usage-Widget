# v2.5.1 — macOS installer fix

A CI-only patch: the macOS `.dmg` installer could come out of the release pipeline corrupted, showing "is damaged and can't be opened" on mount. Windows is unaffected.

## Fixed

- **macOS `.dmg` could fail to mount ("is damaged", extraction also fails).** Tauri's dmg bundler drives Finder via AppleScript to lay out the installer window (background, icon position), and that automation isn't reliable in headless CI — it can report a successful build while quietly writing a corrupted disk image, with no error in the build log. The release workflow now forces the dmg bundler to skip that step, trading a custom-styled installer window (which this project never used anyway) for a dmg that reliably mounts. No app code changed — Windows builds and existing installs are unaffected.

## Notes

- This release is the first real-device check of whether the fix holds — if your `.dmg` still won't mount, please report it.
- All costs are *estimates* derived from local JSONL × official pricing (subscribers are not billed per-token).

## Download

### Windows
- `Claude Widget_2.5.1_x64-setup.exe` — NSIS installer (recommended)
- v2.0.x and later: Settings → "Check for updates" for automatic delivery

### macOS (Apple Silicon)
- `Claude Widget_2.5.1_aarch64.dmg` — DMG installer
- First-launch Gatekeeper bypass: right-click → Open, or `xattr -d com.apple.quarantine "/Applications/Claude Widget.app"`

## System requirements

- Windows 10/11 (Win11 recommended — Mica vibrancy)
- macOS 11 Big Sur or later (Apple Silicon)
- WebView2 Runtime (auto-installed by the Win10 installer)

- **macOS `.dmg`가 마운트되지 않던 문제 ("손상됨", 추출도 실패).** Tauri의 dmg 번들러가 설치 창(배경·아이콘 배치)을 꾸미려고 Finder를 AppleScript로 조작하는데, 이 자동화가 headless CI에서는 원래 안정적으로 동작하지 않습니다 — 빌드 로그에 에러 하나 없이 "성공"으로 끝나면서도 조용히 손상된 디스크 이미지를 만들어낼 수 있습니다. 릴리즈 워크플로가 이제 dmg 번들러의 그 단계를 확실히 건너뛰도록 강제합니다 — 애초에 쓴 적 없는 커스텀 설치 창 스타일 대신, 확실히 마운트되는 dmg를 택했습니다. 앱 코드 변경은 없고, Windows 빌드·기존 설치본은 영향 없습니다.
