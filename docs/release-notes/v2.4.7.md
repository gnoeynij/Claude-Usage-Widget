# v2.4.7 — Start with PC

A small quality-of-life release: the widget can now launch itself when your PC starts.

## What's new

- **"Start with PC" toggle** in Settings (Appearance block, next to Always on top / Dark mode). Turn it on and the widget registers an OS-level login entry — `HKCU` Run key on Windows, a LaunchAgent on macOS — and launches automatically at sign-in. Off by default; toggling off removes the entry immediately. The OS entry is the source of truth, so the switch always reflects reality even if you remove the entry from the OS side (e.g. Task Manager's Startup apps).

## Notes

- Portable-exe users: the login entry points at the exe's current location — if you move the file, re-toggle the switch once to re-register it.
- Windows can also disable startup apps from Task Manager → Startup apps; that override lives outside the registry entry the widget manages, so the toggle may still show ON in that case.
- macOS: implemented via LaunchAgent but not yet field-verified on real hardware (same as the login-terminal path from v2.4.6).
- All costs are *estimates* derived from local JSONL × official pricing (subscribers are not billed per-token).

## Download

### Windows
- `Claude Widget_2.4.7_x64-setup.exe` — NSIS installer (recommended)
- v2.0.x and later: Settings → "Check for updates" for automatic delivery

### macOS (Apple Silicon)
- `Claude Widget_2.4.7_aarch64.dmg` — DMG installer
- First-launch Gatekeeper bypass: right-click → Open, or `xattr -d com.apple.quarantine "/Applications/Claude Widget.app"`

## System requirements

- Windows 10/11 (Win11 recommended — Mica vibrancy)
- macOS 11 Big Sur or later (Apple Silicon)
- WebView2 Runtime (auto-installed by the Win10 installer)

## 새 기능

- **"PC 시작 시 자동 실행" 토글** — 설정의 Appearance 블록(항상 위 / 다크 모드 옆)에 추가. 켜면 OS 레벨 로그인 항목(Windows는 `HKCU` Run 레지스트리, macOS는 LaunchAgent)이 등록되어 로그인 시 자동 실행됩니다. 기본값 OFF, 끄면 항목이 즉시 삭제됩니다. OS 항목이 진실의 출처라서 — OS 쪽에서 직접 항목을 지워도 스위치가 실제 상태를 반영합니다.

## 비고

- 포터블 exe 사용자: 로그인 항목이 exe의 현재 위치를 가리키므로, 파일을 옮겼다면 토글을 한 번 껐다 켜서 재등록해 주세요.
- Windows 작업 관리자 → 시작 앱에서 끈 경우: 그 차단은 위젯이 관리하는 레지스트리 항목 바깥에 있어서 토글이 여전히 ON으로 보일 수 있습니다.
- macOS: LaunchAgent 방식으로 구현되어 있으나 실기기 검증 전입니다 (v2.4.6의 로그인 터미널 경로와 동일).
- 모든 비용은 로컬 JSONL × 공식 단가표 기반 *추정치*입니다(구독 사용자는 실제 토큰당 과금 없음).
