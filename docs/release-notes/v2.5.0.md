# v2.5.0 — The instrument era

**Why 2.5:** the instrument theme — the retro LCD panel skin with the
seven-segment session readout and block gauges — deserved a minor version of
its own. It shipped across the v2.4.9/v2.4.10 patches; 2.5 names that
generation properly. In case you missed it, the instrument era so far:

- **Instrument theme** (v2.4.9) — a second visual grammar next to Liquid
  Glass: 7-seg session hero, block-gauge weekly rows, zone insets. Same
  graphite/silver palette, switchable in Settings → Theme.
- **Settings rebuilt as inset groups** (v2.4.9) — Appearance / General /
  Combined across devices / About, Apple-style.
- **The guide wears your theme** (v2.4.9) — instrument users see the
  instrument replica with callouts written for what they actually see.
- **Fixes along the way** (v2.4.10) — Opus 5 usage no longer counts as $0,
  and the $25k milestone toast can actually be dismissed.

## What's new in 2.5.0

- **Limit toasts fire once again — literally once.** The 85%/95% threshold
  toast and the "on pace to hit the limit" alert were re-firing on every
  sync: the API started recomputing `resets_at` per request, so the same
  window's timestamp jitters by a second or so between polls, and the
  exact-match dedup read every sync as a fresh window. Window identity now
  uses a 10-minute tolerance (real windows are ≥5h apart), guarded by unit
  tests pinned to the actual observed jitter.
- **Mini (instrument) alignment pass.** The weekly column now sits on the
  session zone's grid: ALL MODELS caps share SESSION's glyph line, the FABLE
  gauge shares the digits' bottom line, each label+gauge reads as a tight
  unit (6px), and the warning badge nudged into balance. The last gauge no
  longer touches the panel's bottom edge.
