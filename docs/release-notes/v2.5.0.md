# v2.5.0 — The instrument era

**Why 2.5:** the instrument theme — the retro LCD panel skin with the seven-segment session readout and block gauges — deserved a minor version of its own. It shipped across the v2.4.9/v2.4.10 patches; 2.5 names that generation properly. In case you missed it, the instrument era so far:

- **Instrument theme** (v2.4.9) — a second visual grammar next to Liquid Glass: 7-seg session hero, block-gauge weekly rows, zone insets. Same graphite/silver palette, switchable in Settings → Theme.
- **Settings rebuilt as inset groups** (v2.4.9) — Appearance / General / Combined across devices / About, Apple-style.
- **The guide wears your theme** (v2.4.9) — instrument users see the instrument replica with callouts written for what they actually see.
- **Fixes along the way** (v2.4.10) — Opus 5 usage no longer counts as $0, and the $25k milestone toast can actually be dismissed.

## What's new in 2.5.0

- **Limit toasts fire once again — literally once.** The 85%/95% threshold toast and the "on pace to hit the limit" alert were re-firing on every sync: the API started recomputing `resets_at` per request, so the same window's timestamp jitters by a second or so between polls, and the exact-match dedup read every sync as a fresh window. Window identity now uses a 10-minute tolerance (real windows are ≥5h apart), guarded by unit tests pinned to the actual observed jitter.
- **Mini (instrument) alignment pass.** The weekly column now sits on the session zone's grid: ALL MODELS caps share SESSION's glyph line, the FABLE gauge shares the digits' bottom line, each label+gauge reads as a tight unit (6px), and the warning badge nudged into balance. The last gauge no longer touches the panel's bottom edge.

## 새 기능

- **한도 토스트가 다시 — 말 그대로 — 한 번만 뜹니다.** 85%/95% 임계 토스트와 "한도 도달 예상" 알림이 매 동기화마다 재발화하고 있었습니다: API가 `resets_at`을 요청마다 재계산하게 되면서 같은 윈도우의 타임스탬프가 폴링 사이 1초 안팎으로 흔들리고, 정확 일치 방식의 중복 방지가 매 동기화를 새 윈도우로 읽은 겁니다. 이제 윈도우 판정에 10분 허용오차를 사용하고(실제 윈도우 간격은 5시간 이상), 실측 지터 값을 고정한 단위 테스트로 가드합니다.
- **미니(계기판) 정렬 패스.** 주간 컬럼이 세션 존의 그리드에 앉습니다: ALL MODELS 캡스가 SESSION 글리프 라인을, FABLE 게이지가 숫자 바닥 라인을 공유하고, 라벨+게이지가 밀착 유닛(6px)으로 읽히며, 경고 배지 위치도 균형을 맞췄습니다. 마지막 게이지가 패널 바닥에 붙지 않습니다.
