# v2.5.6 — Ultra plan support

Anthropic's October 30 plan change renamed Max 20× to **Ultra** and removed the 5-hour limit for verified Ultra accounts. The usage API now reports that missing limit in a way the widget couldn't read, so every sync failed. This release fixes that, adapts the layout to weekly-only plans, and corrects two model prices.

## Fixed

- **"Sync failed" on every refresh for Ultra accounts.** For plans without a 5-hour limit the usage API sends the 5-hour block as empty (`null`) instead of leaving it out, and the widget rejected the whole response. Every usage block is now optional, so a missing limit no longer breaks the sync.
- **Claude Haiku 5.5 showed $0.** It had no price entry. It's now priced from the official table, including the higher rate for prompts over 100k tokens.
- **Claude Sonnet 5.5 cache reads were priced 2× too high** ($0.20 instead of $0.10 per million tokens).

## Changed

- **Plans without a 5-hour limit (Ultra):**
  - The donut / hero shows weekly usage and its projection, and the duplicate All models row and caption drop out.
  - Mini (240×88) and Normal (320×300) shrink to fit. A size you set yourself is kept.
  - Detail's active-block strip no longer shows a 5-hour countdown.
  - The widget remembers the plan between launches, so it starts at the right size before the first sync.
- **The Settings plan chip** reads **Ultra** (formerly Max 20×) or **Max** (formerly Max 5×).
- **The interactive guide** explains the weekly hero on plans without a 5-hour limit.

## Notes

- **Your stored cost history is recalculated once** from the logs still on disk, so the price fixes reach past days. Sonnet 5.5 days go down, Haiku 5.5 days go up. Days whose logs have been cleaned up keep their previous values.
- Plans that still have a 5-hour limit (Free, Pro, Max, and Ultra accounts not yet verified) look and behave as before.
- All costs are *estimates* derived from local JSONL × official pricing (subscribers are not billed per-token).

<summary>한국어</summary>

10월 30일 Anthropic 플랜 개편으로 Max 20×가 **Ultra**로 이름이 바뀌었고, 인증된 Ultra 계정은 5시간 한도가 없어졌습니다. 사용량 API가 없어진 한도를 위젯이 읽지 못하는 형태로 보내서 동기화가 매번 실패했습니다. 이번 릴리즈는 그 문제를 고치고, 주간 한도만 있는 플랜에 맞게 화면을 조정하고, 모델 단가 두 건을 바로잡습니다.

## 수정

- **Ultra 계정에서 매번 "동기화 실패"가 뜨던 문제.** 5시간 한도가 없는 플랜에서는 사용량 API가 5시간 블록을 빼지 않고 빈 값(`null`)으로 보내는데, 위젯이 응답 전체를 거부했습니다. 이제 모든 사용량 블록이 선택 항목이라 한도 하나가 없어도 동기화가 깨지지 않습니다.
- **Claude Haiku 5.5 비용이 $0으로 표시되던 문제.** 단가 항목이 없었습니다. 공식 단가표대로 추가했고, 프롬프트가 10만 토큰을 넘을 때의 높은 단가도 반영했습니다.
- **Claude Sonnet 5.5 캐시 읽기 단가가 2배로 계산되던 문제** (백만 토큰당 $0.10이 아니라 $0.20).

## 변경

- **5시간 한도가 없는 플랜(Ultra):**
  - 도넛/hero가 주간 사용량과 그 투영을 표시하고, 중복되는 전체 모델 행과 캡션이 빠집니다.
  - Mini(240×88)와 Normal(320×300)이 그에 맞춰 줄어듭니다. 직접 조정한 크기는 유지됩니다.
  - Detail의 활성 블록 줄에 5시간 카운트다운이 더 이상 표시되지 않습니다.
  - 플랜을 실행 사이에 기억해 첫 동기화 전부터 맞는 크기로 뜹니다.
- **설정 패널 플랜 칩**이 **Ultra**(구 Max 20×) 또는 **Max**(구 Max 5×)로 표시됩니다.
- **인터랙티브 가이드**에 5시간 한도가 없는 플랜의 주간 hero 설명을 추가했습니다.

## 비고

- **저장된 비용 이력을 한 번 다시 계산합니다.** 디스크에 남아 있는 로그로 계산해 단가 수정이 지난 날짜에도 반영됩니다. Sonnet 5.5를 쓴 날은 내려가고 Haiku 5.5를 쓴 날은 올라갑니다. 로그가 이미 정리된 날짜는 기존 값이 유지됩니다.
- 5시간 한도가 남아 있는 플랜(Free, Pro, Max, 아직 인증되지 않은 Ultra 계정)은 화면과 동작이 이전과 같습니다.
- 모든 비용은 로컬 JSONL × 공식 단가표 기반 *추정치*입니다(구독 사용자는 실제 토큰당 과금 없음).
