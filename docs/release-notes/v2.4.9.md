# v2.4.9 — Settings redesign & theme-aware guide

The settings panel gets a proper Apple-style grouped layout, and the guide
now renders your actual theme — instrument users finally see instrument
explanations.

## What's new

- **Settings, regrouped.** The panel is now four inset groups — Appearance
  (theme · dark · always-on-top · opacity), General (language · auto-sync ·
  start with PC), Combined across devices, About (guide · updates) — with
  hairline row separators and a single accent action. The sync folder shows
  its name instead of a full path (full path on hover), and the version moved
  next to "Check for updates".
- **The guide wears your theme.** Opening the guide from an instrument-themed
  widget now shows the instrument replica, with callouts rewritten for what
  you actually see: seven-segment digits and caption projections instead of
  donut arcs, block gauges instead of capsule bars. Glass users see the
  original guide unchanged.
- **Manual sync now answers visibly.** Clicking the session hero (donut or
  digits) replays the gauge from 0 to the current value (750 ms), so a manual
  refresh has unmistakable feedback. Automatic syncs stay silent.

## Fixed

- **Every mode now remembers your size.** Normal silently snapped back to its
  default size on every mode switch or restart; it now restores your last
  resized size like Mini and Detail.
- **Detail opens without a scrollbar.** The default size is now the exact
  no-scroll fit (520×644), and the scroll area reserves a stable scrollbar
  gutter — previously the classic scrollbar's width could re-wrap labels and
  lock the panel into a "scrollbar begets scrollbar" state depending on how
  you entered the mode.
- **Korean no longer breaks mid-word.** Text across the widget, settings, and
  guide wraps at word boundaries (`keep-all`) instead of splitting eojeol
  like "사용합 / 니다". English is unaffected.
- Weekly limit numbers in the instrument Normal view carry the `%` unit,
  matching the session hero and Mini.
- **Mini (instrument): weekly % values were muted gray** — they now use the
  same full-contrast white and weight as Normal's rows (labels stay microcaps
  gray).
- **Mini: the corner warning badge no longer collides with the first weekly
  %** — while the badge shows, the weekly rows drop below its lane (layout is
  untouched when there's no badge).
- Guide wording polish in both languages (consistent 초기화 terminology,
  label-accurate English, wider callout/paragraph measures in the guide
  window).
