# v2.4.8 — Fable weekly row & right-click menu

The weekly section now mirrors the official Claude apps — including the Fable
cap — and the widget gains a proper right-click menu.

## What's new

- **Server-labeled weekly rows.** Anthropic replaced the fixed per-model
  weekly fields with a generic `limits` array, and the widget now renders it
  directly: whatever scoped cap your plan tracks (currently **Fable** on
  Max/Team-premium plans) appears as its own row with the server's label —
  and when Anthropic re-scopes the cap to another model, the widget follows
  automatically, no update needed. The retired "Sonnet only" row no longer
  shows a meaningless 0% on plans that don't have it.
- **Right-click menu.** Right-click anywhere on the widget for quick actions:
  **copy a one-line usage summary** (session/weekly/scoped % + today's cost),
  sync now, switch modes, hide, open the log folder, and **click-through
  mode** — the widget ignores the mouse so you can work through it (restore
  via tray right-click → "Disable click-through"). Works on every surface,
  including the drag areas where Windows used to show the window system menu.

## Fixed

- **Windows: drag-area right-click showed the OS system menu** (move/size/
  close) instead of the widget menu — WebView2 hands those clicks to the
  window caption, so the widget now intercepts at the native level and opens
  its own menu there too.
- **Settings scrollbar ran through the card's rounded corners** when the
  panel overflowed (it appeared after the auto-start toggle landed).
  Scrolling now lives inside the card with the header pinned.

## Notes

- **Reading the Fable row:** its percentage is measured against the Fable
  allowance included in your plan (up to 50% of the weekly limit on Max), not
  against the whole weekly limit — so it can legitimately show a higher
  number than "All models". When it reaches 100%, that allowance is used up
  and Fable continues via usage credits or another model.
- macOS: the right-click menu works everywhere by design (no system-menu
  quirk), but this release's paths remain field-unverified on real hardware.
- All costs are *estimates* derived from local JSONL × official pricing
  (subscribers are not billed per-token).

## 새 기능

- **서버 라벨 주간 행.** Anthropic이 고정 모델별 주간 필드를 범용 `limits`
  배열로 교체했고, 위젯이 이제 이를 직접 렌더링합니다: 플랜이 추적하는
  스코프 한도(현재 Max/Team 프리미엄의 **Fable**)가 서버 라벨 그대로 별도
  행으로 표시되고 — Anthropic이 대상 모델을 갈아끼워도 위젯은 업데이트
  없이 자동 추종합니다. 은퇴한 "Sonnet only" 행이 해당 없는 플랜에서
  무의미한 0%로 남지 않습니다.
- **우클릭 메뉴.** 위젯 아무 곳이나 우클릭하면 빠른 액션: **사용량 요약
  한 줄 복사**(세션/주간/스코프 % + 오늘 비용), 지금 동기화, 모드 전환,
  숨기기, 로그 폴더 열기, 그리고 **클릭 통과 모드** — 위젯이 마우스를
  통과시켜 뒤 창을 그대로 조작할 수 있습니다(해제는 트레이 우클릭 →
  "클릭 통과 해제"). Windows에서 시스템 메뉴가 뜨던 드래그 영역을 포함해
  모든 표면에서 동작합니다.

## 수정

- **Windows: 드래그 영역 우클릭 시 위젯 메뉴 대신 OS 시스템 메뉴**(이동/
  크기/닫기)가 뜨던 문제 — WebView2가 해당 클릭을 창 캡션으로 넘기는
  구조라, 네이티브 레벨에서 가로채 위젯 메뉴를 띄우도록 했습니다.
- **설정 패널 스크롤바가 카드 둥근 모서리를 관통**하던 문제(자동 실행
  토글 추가로 내용이 넘치며 드러남) — 스크롤을 카드 안쪽으로 옮기고
  제목 줄은 고정했습니다.

## 비고

- **Fable 행 읽는 법:** 이 행의 %는 전체 주간 한도가 아니라 **플랜에
  포함된 Fable 몫**(Max는 주간 한도의 최대 50%) 기준입니다 — 그래서
  "All models"보다 높게 보일 수 있습니다. 100%에 도달하면 그 몫이 소진된
  것이고, 이후 Fable은 usage credit 또는 다른 모델로 이어집니다.
- macOS: 우클릭 메뉴는 구조상 전 영역에서 동작하지만(시스템 메뉴 문제
  없음), 이번 릴리즈 경로들의 실기기 검증은 아직입니다.
- 모든 비용은 로컬 JSONL × 공식 단가표 기반 *추정치*입니다(구독 사용자는
  실제 토큰당 과금 없음).
